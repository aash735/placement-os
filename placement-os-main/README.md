Placement OS Tracker 🎯

A full-stack placement preparation platform designed to help students streamline DSA practice, mock tests, progress tracking, revision, and structured learning — all in one place.

Built to solve a real problem faced during placement preparation: scattered resources, inconsistent tracking, and lack of a centralized workflow.

⚙️ Installation & Setup
1️⃣ Clone the repository
git clone <your-repository-url>
cd placement-os
2️⃣ Install dependencies
npm install
3️⃣ Configure environment variables

Create a .env.local file:

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
4️⃣ Run development server
npm run dev

Visit:

http://localhost:3000

🎯 Why I Built This

I built Placement OS Tracker to create a structured and centralized system for placement preparation.

While preparing myself, I realized most students struggle with:

scattered DSA resources
inconsistent tracking
lack of revision systems
no unified preparation workflow

This project aims to solve that by combining preparation, tracking, analytics, and productivity into a single platform.
